# ✈️ Travel Go — Travel Website

**Travel Go** is a responsive travel and tourism website frontend designed to provide users with an attractive and user-friendly platform for exploring travel destinations and experiences.

The project is built entirely using **HTML, CSS, and JavaScript**, without any frontend framework.

---

## 🌍 Features

* 🏠 **Home Page**

  * Attractive travel-themed landing page
  * Hero section with travel content
  * Featured destinations and experiences

* 🗺️ **Explore Destinations**

  * Display of different travel destinations
  * Destination images and information
  * Easy-to-use navigation

* 🎨 **Modern User Interface**

  * Clean and visually appealing design
  * Travel-themed layout
  * Interactive sections and elements

* 📱 **Responsive Design**

  * Works across desktop, tablet, and mobile devices
  * Mobile-friendly layout

* ⚡ **JavaScript Interactions**

  * Interactive buttons and navigation
  * Dynamic UI elements
  * Client-side functionality

* 📞 **Contact Section**

  * Contact information
  * User-friendly contact interface

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sudiprakshit05/travel-go.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd travel-go
```

### 3. Run the Website

Since this is a pure HTML, CSS, and JavaScript project, no package installation is required.

Simply open:

```text
index.html
```

in your web browser.

You can also use **Visual Studio Code with the Live Server extension** for easier development.

## 💻 How It Works

### HTML

HTML5 is used to create the basic structure of the website, including:

* Navigation bar
* Hero sections
* Destination cards
* Information sections
* Contact section
* Footer

### CSS

CSS3 is used for:

* Website layout
* Colors and typography
* Flexbox/Grid
* Responsive design
* Hover effects
* Animations
* Mobile layouts

### JavaScript

JavaScript is used to add interactivity and dynamic behavior to the website, such as:

* Navigation interactions
* Buttons
* Menus
* UI interactions
* Dynamic content

## 📱 Responsive Design

Travel Go is designed to provide a consistent experience across different screen sizes.

The website supports:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

CSS media queries are used to adapt the layout for different screen sizes.
